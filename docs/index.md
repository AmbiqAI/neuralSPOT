## neuralSPOT is in maintenance

neuralSPOT is no longer under active development. New firmware work happens in [neuralSPOT-X](https://ambiqai.github.io/neuralspotx/), and the AI tooling that started in neuralSPOT is now part of the HELIA tools. This site stays online for existing users. Security fixes may still be released; see the [releases](https://github.com/AmbiqAI/neuralSPOT/releases).

## Where things moved

| If you used | Go to |
|---|---|
| neuralSPOT libraries, examples and build system | [neuralSPOT-X](https://ambiqai.github.io/neuralspotx/) and its [migration guide](https://ambiqai.github.io/neuralspotx/getting-started/migrate-from-neuralspot/) |
| AutoDeploy for model profiling and power measurement | [heliaPROFILER](https://ambiqai.github.io/helia-profiler/) |
| AutoDeploy model library and code generation | [heliaAOT](https://ambiqai.github.io/helia-aot/) |
| The TFLM runtime | [heliaRT](https://ambiqai.github.io/helia-rt/) |
| Feature extraction (MFCC, filters, FFT) | [heliaDSP](https://ambiqai.github.io/helia-dsp/) |
| Audio demos (speech enhancement, keyword spotting, speaker ID) | [soundKIT](https://ambiqai.github.io/soundkit/) |
| Web dashboards for EVB data | [Tileio](https://ambiqai.github.io/tileio/) |

## Legacy documentation

The original neuralSPOT documentation is still available from the navigation menu. Each page notes where its topic lives now. The source code is on [GitHub](https://github.com/AmbiqAI/neuralSPOT).
